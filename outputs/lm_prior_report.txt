================================================================
 LM PRIOR SWEEP: does an LM prior fix the Goodhart failure?
================================================================

Setup:
  N=64 problems (first 64 of GSM8K test)
  K=32 soft prompt tokens
  Reference LM: fresh base Llama-3.2-1B (no CODI LoRA)
  LM loss: cross-entropy between
             softmax(sharpness * cos(e_i, embed_v))
           and the reference LM's autoregressive predictive logits at
           position i-1. Sharpness=50.0. Specials masked out.
  Multi-host: 4 TPU workers in parallel, one lm_weight per worker.

4. CONCLUSION

    The LM prior successfully moves the projected tokens onto the
    natural-text manifold — instead of random unicode / special tokens,
    we now get grammatical stopword chains.

    But it does NOT carry the reasoning content. Behavioral equivalence
    is not improved by the LM prior: the best config (lm_w=0.1) gets
    21.88% gold / 37.5% agreement, roughly the same as no-prior K=32
    (24.41% / 38.09%). Both are still WORSE than the empty-wrapper
    baseline (31.64% / 63.87%).

    Why: the LM prior is SELF-REFERENTIAL — it asks "is e_i plausible
    as the next token given the prior soft embeddings e_<i?". Given a
    weird leading context, common fillers ('the', ',', '.') are always
    the minimum-surprise answer. So the optimizer finds a sequence of
    filler tokens whose hidden-state trajectory happens to land at
    h_target, but whose content is just as meaningless as before.

    A real fix would need a non-self-referential prior, e.g.:
      (a) Teacher-forced discrete token search with straight-through
          estimator — each step, hard-project to argmax, feed REAL
          token embeddings to the ref LM, compute auto-regressive log
          prob, backprop via STE.
      (b) Explicit beam search over token sequences with reconstruction
          as the reward.
      (c) Target CODI's final answer logits rather than h_target —
          a behavioral criterion that sidesteps the hidden-state
          adversarial manifold entirely.

    All three are more work and I'm stopping here to report results
    rather than proceed without discussion.

    Main takeaway (reinforced): the empty-structural-wrapper baseline
    ([q, <|bocot|>, <|eocot|>] with NO reasoning content whatsoever)
    remains the strongest way to make the model behave like CODI on
    this task. CODI's latent reasoning contributes ~7pp of gold accuracy
    over the wrapper, and none of our projection/reconstruction
    approaches have been able to transfer even that residual gain.
